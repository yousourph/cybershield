# 🛡️ CyberShield

### YOUR PERSONAL SECURITY GUIDE

CyberShield is a Flutter-based cybersecurity awareness application designed to help users understand common cyber threats, recognise phishing attempts, and develop safer online habits.

🌐 **[Launch CyberShield](https://yousourph.github.io/cybershield/)**

---

## ✨ Features

- **Cybersecurity Quiz** — Test your cybersecurity knowledge with interactive questions, instant feedback, and scores.
- **Cyber Threats & Safety Guide** — Learn about phishing, malware, social engineering, identity theft, online scams, and public Wi-Fi risks.
- **Phishing Awareness** — Explore phishing examples, learn to identify warning signs, and test your ability to recognise suspicious messages.
- **Daily Cybersecurity Tips** — Discover practical tips for improving your online safety.
- **About CyberShield** — Learn about the purpose of the application.
- **About the Author** — Learn about the developer and his interest in cybersecurity and technology.

## 🎯 Project Purpose

CyberShield aims to make cybersecurity awareness more accessible by presenting important security concepts in a simple, interactive, and beginner-friendly mobile application.

## 🚀 Getting Started

### Prerequisites

Install the [Flutter SDK](https://docs.flutter.dev/get-started/install) and a suitable development environment, such as [Visual Studio Code](https://code.visualstudio.com/).

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/yousourph/cybershield.git
   ```

2. Navigate to the project directory:

   ```bash
   cd cybershield
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

To run the web version locally, use:

```bash
flutter run -d chrome
```

## 📂 Project Structure

The application uses a modular structure to organise its source code:

- `lib/data/` — Cybersecurity tips, threats, and quiz content
- `lib/models/` — Data models
- `lib/screens/` — Application screens
- `lib/theme/` — Application colours and theme styling
- `lib/widgets/` — Reusable user interface components
- `assets/` — Application assets, including images
